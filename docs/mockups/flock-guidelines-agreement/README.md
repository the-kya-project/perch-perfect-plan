# Flock guidelines agreement and flagging: approved mockups

Brittany approved these on Nov 28, 2026. They're static HTML exports of the design canvas, so open them in a browser or read the markup for exact layout, colors, type, and spacing. Each screen is 390px wide.

1. 01-what-were-all-about.html is walk-through screen 1. It scrolls, and the Next button is pinned at the bottom of the phone screen in the real app.
2. 02-how-we-look-after-each-other.html is walk-through screen 2.
3. 03-promises-and-agreement.html is walk-through screen 3, with the agree button.
4. 04-post-options-sheet.html is the sheet that opens from the "..." menu on another member's post. A member's own posts keep Edit and Delete.
5. 05-flag-sheet.html is the flag sheet, shown with one reason picked. The send button stays greyed out until a reason is picked.
6. 06-flag-sent.html is the confirmation after sending. Its second paragraph changes by reason (see the comment in the file).

The mockups show the feed's post card and header only as background. The bottom navigation and side menu follow the separate navigation work.
